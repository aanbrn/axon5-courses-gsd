# ADR-0008: Build metadata is reproducible

Date: 2026-11-11

Status: Accepted

## Context

Spring Boot's build-info and a static SPA have no version beyond the image tag. Including the build
timestamp makes otherwise identical rebuilds produce a different metadata layer.

## Decision

`bootBuildInfo` excludes `time`: `META-INF/build-info.properties` carries artifact, group, name and
version only. The frontend mirrors it with `build-info.json` in `build/dist` (same fields, no
timestamp), served by nginx at `/build-info.json`. Both are generated by Gradle, not by hand.

## Alternatives considered

- Keep the timestamp — useful for support, but breaks layer reproducibility and adds nothing the
  image tag does not already say.
- No build info — loses the metadata embedded in the artifact.

## Consequences

- Rebuilding the same source produces the same metadata layer.
- The version is available from the jar and from `/build-info.json` without a running JVM endpoint.
